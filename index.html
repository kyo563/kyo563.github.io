配信中の操作を、シンプルに。

01 / QUEUE

コメントから待機列へ

コメントの受信はわんコメに任せ、参加希望の解析と待機列の管理をプラグインが行います。管理画面ではドラッグで順番を変更できます。

02 / OBS

配信画面で順番を共有

縦・横のレイアウト、表示文言、フォント、文字サイズ、背景色・透過度を設定できます。設定と待機列は利用者のPCに保存します。

03 / BOT

共通Botで必要な案内だけ

次グループの呼び出し、Botへの呼びかけに対する待機順の返信、待機人数・グループ数の定期案内を個別に選択できます。

JoinQueue Bot の接続について

  1. 配信するチャンネルで、@JoinQueueBotを標準モデレーターに登録します。
  2. プラグインの設定画面でBot設定を開き、配信者自身のGoogleアカウントでチャンネルを認証します。
  3. わんコメの接続先と合わせた配信を選び、接続を確認して通知を有効にします。

配信者にはチャンネルの所有確認のため、YouTubeの読み取り専用権限を要求します。共通Botの投稿用認証情報はサーバーで管理し、プラグインへ配布しません。

共通Botの一般提供に向けてGoogle OAuth審査の準備中です。現在のGoogle認証はテスト対象者に限られます。メンバー限定配信でのBot投稿は、対応確認前のため保証しません。待機列・OBS表示はBot接続とは別に利用できます。

Google認証の前にプライバシーポリシーと利用に関するご案内をご確認ください。

About JoinQueue Bot

JoinQueue Bot is a shared YouTube live-chat notification service for the OneComme waiting-list plugin. OneComme receives comments; the local plugin manages the queue and OBS display. Our backend validates the stream and posts queue notifications using the shared Bot account.

Creators authorize youtube.readonly to prove channel ownership. Their Google access token is not persisted, and no creator refresh token is requested. Only the service operator authorizes youtube.force-ssl for the shared Bot. Public availability is being prepared; OAuth verification is not yet complete.

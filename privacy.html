プライバシーポリシー

2026年10月1日 / 作者・運営：kyo563 / お問い合わせ：joinqueue.bot@gmail.com

本ポリシーは、待機列整理アプリ（わんコメ連携版）と共通Bot「JoinQueue Bot」の接続・通知機能に適用します。本サービスはYouTube API Servicesを使用します。現在の実装における情報の取り扱いを以下に説明します。

1. 利用者のPCで処理・保存する情報

わんコメから受け取ったコメントを解析し、参加者情報、ハンドル・表示名・申告名、待機列、参加履歴、わんコメのメモ、表示設定、必要な接続情報をPC内へ保存します。再起動後の復元と待機列の管理に使用します。わんコメのGoogleログイン情報やパスワードを取得することはありません。

2. 配信者のGoogle認証

配信チャンネルの所有確認のため、Googleの認証画面でYouTubeの読み取り専用権限（youtube.readonly）を要求し、Google公式APIのchannels.list（mine=true）で所有チャンネルIDを確認します。Google認証のパスワードはGoogleに入力し、本サービスへ入力する必要はありません。

配信者のGoogleアクセストークンは所有確認の処理中に使用するだけで、サーバーやプラグインへ継続保存しません。配信者のリフレッシュトークンは要求しません。確認後は確認済みチャンネルIDと本サービス専用の端末接続情報を使用します。プラグイン内の端末キーはWindows DPAPIで保護します。

3. Bot通知のためサーバーへ送る情報

Bot機能を使う場合、端末認証情報、配信ID、通知種別、投稿に必要な表示名・ハンドル名、待機順、グループ番号、人数などを共通バックエンドへ送ります。配信の所有者と稼働状況を検証し、要求された通知をYouTubeライブチャットへ投稿します。投稿した文面は対象ライブチャットで公開されます。

受信コメント履歴の全体、わんコメのメモ、フォントファイルを共通Botサーバーへ送ることはありません。コメントの取得はわんコメが行い、共通Botサーバーで重複取得しません。

共通Botの投稿用権限（youtube.force-ssl）は運営者がBot用アカウントで認証します。この権限を配信者のチャンネル接続時に要求することはありません。Botの秘密情報・リフレッシュトークンはサーバー側で暗号化保存し、利用者へ配布しません。

4. サーバー保存情報と用途

確認済みチャンネルID、利用者・接続・端末識別子、端末キーのハッシュ、認証確認日時、失効状態、投稿要求の識別子・時刻・ハッシュ・処理結果を保存します。接続管理、不正利用の防止、投稿先検証、レート制限、連投・重複防止、不具合調査に使用します。投稿台帳へ投稿本文そのものを保存しません。

サーバーへの通信元について、不正な認証要求の制限に用いるハッシュ値を一時的に保存します。サーバーの診断ログには要求識別子・状態・エラーコード等を記録します。Googleのトークンやパスワードを診断ログへ記録しません。

現在、端末接続キーの有効期間は30日です。期限切れや接続解除により利用できなくなりますが、接続記録や投稿台帳が自動的にすべて削除される仕組みはまだありません。一般提供の開始前に保存期限と削除手続きを整備し、本ページを更新します。現時点のGoogle認証はテスト対象者に限られます。

5. 接続解除・データ削除に関するお問い合わせ

プラグインのBot設定で接続を解除すると、サーバー側の端末・チャンネル接続が失効し、PCの端末接続キーを削除します。接続解除だけでサーバーの過去の記録がすべて消えるわけではありません。

PC内の保存データは設定画面の完全初期化で削除できます。サーバー側の保存情報の削除については、joinqueue.bot@gmail.comへご連絡ください。対象チャンネルの特定と所有確認が必要です。問い合わせ時にGoogleパスワード、OAuthトークン、端末キーを送らないでください。

Googleによる本サービスへのアクセス許可は、Googleアカウントのサードパーティ接続設定から取り消せます。本サービス内の接続解除・保存データ削除とは別の操作です。

本サービスの保存データを削除しても、YouTubeにすでに投稿された通知は自動的に削除されません。YouTube上のデータの管理はYouTube側の機能をご利用ください。

6. 外部サービスと情報共有

接続と投稿にGoogle/YouTube、バックエンドの通信・保存基盤にCloudflare、案内サイトの配信にGitHub Pagesを使用します。これらの提供者はサービスの運営・保護のために通信情報等を処理する場合があります。Googleユーザーデータを広告目的で販売したり、第三者のAIモデルの学習へ提供したりすることはありません。

Google APIから受け取った情報の利用・他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

7. 変更とお問い合わせ

機能や情報の取り扱いを変更する場合は、このページと必要なアプリ内案内を更新します。プライバシーに関するご質問やご相談は、運営者kyo563（joinqueue.bot@gmail.com）までご連絡ください。

Privacy summary in English

Developer/operator: kyo563. Contact: joinqueue.bot@gmail.com. Queue data and OneComme memos are stored locally. Creator authorization uses youtube.readonly for channel ownership verification only; creator access tokens are not persisted and creator refresh tokens are not requested. The shared Bot uses operator-only youtube.force-ssl authorization, encrypted on the server.

Notification requests contain the destination stream and the names/queue information necessary for the selected notification. The backend does not receive all comment history, OneComme memos or font files. It stores connection IDs, verified channel IDs, credential hashes, timestamps and posting metadata/hashes/results, not the full notification text. Cloudflare hosts the backend; GitHub Pages hosts this site; Google/YouTube provides authorization and chat posting.

Disconnect revokes the service connection but does not erase all historical records. Automatic expiry/deletion of all stored records is not enabled in production; public availability is being prepared. Contact the operator for deletion enquiries without sending passwords or tokens. Google access can be revoked using the Google Account permissions link above. Deleting service data does not delete messages already posted on YouTube.

Our use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
